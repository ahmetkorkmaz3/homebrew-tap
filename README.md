# ahmetkorkmaz3/homebrew-tap

Homebrew casks for [Clipaste](https://github.com/ahmetkorkmaz3/clipaste) and [MJML App](https://github.com/ahmetkorkmaz3/mjml-app).

## Install

```sh
brew install --cask ahmetkorkmaz3/tap/clipaste
brew install --cask ahmetkorkmaz3/tap/mjml-app
```

## Update

The release workflow of each app updates its cask for each new version. Do not edit the casks here. Edit the cask in the repository of the app:

| Cask                  | Source                                                      |
| --------------------- | ----------------------------------------------------------- |
| `Casks/clipaste.rb`   | `homebrew/clipaste.rb` in the Clipaste repository           |
| `Casks/mjml-app.rb`   | `homebrew/mjml-app.rb` in the MJML App repository           |
