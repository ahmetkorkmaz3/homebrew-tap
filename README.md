# ahmetkorkmaz3/homebrew-tap

Homebrew casks for [Clipaste](https://github.com/ahmetkorkmaz3/clipaste).

## Install

```sh
brew install --cask ahmetkorkmaz3/tap/clipaste
```

## Update

The Clipaste release workflow updates `Casks/clipaste.rb` for each new version. Do not edit the cask here. Edit `homebrew/clipaste.rb` in the Clipaste repository.
